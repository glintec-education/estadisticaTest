Niveles de acceso:  1. operador.  2. supervisor y gerente  Acceso a partir de gerarquias, en la que el programa solo permite desplegar una ventana grafica dependiendo de los nivels de acceso que tiene cada persona. Catalogado como operador, supervisor y gerente.El usuario con gerarquia de operador nivel 2 puede accesar a la ventana de trabajo en la cual se despliegan los productos que fabrica la empresa, una vez elejido uno de ellos se despliega otra ventana para realizar la eleccion de la combinacion de colores del producto, misma que selecciona. En caso de estar conforme con las elecciones, se presiona el boton de continuar generando un evento depantalla en la que se muestran las caracteristicas del producto preguntando si son las correctas para realizar la impresion de la etiqueta respectiva.Para el ususario con gerarquia de supervisor cuyo nivel es establecido a 1, la ventana inicial se corresponde con un conjunto de campos relacionados para la creacion de un nuevo producto en la base de datos, ésta actualizará a los elementos que observará el operador asimismo, tiene permisos de generar a nuevos usuarios para la manipulacion del software.
